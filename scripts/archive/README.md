# ארכיון סקריפטים חד-פעמיים (Historical / one-shot scripts)

הקבצים בתיקייה זו הם סקריפטי מיגרציה חד-פעמיים שכבר בוצעו במלואם על `gui.py` / `updater.py`.
הם נשמרים כאן לתיעוד היסטורי בלבד.

> ⚠️ **אין להריץ אותם שוב.** כל אחד מהם מבצע החלפות מחרוזת "עיוורות" (`str.replace` / `re.sub`)
> על קובץ המקור, בלי לבדוק שהתבנית אכן נמצאה ובלי גיבוי. הרצה חוזרת על קוד ששונה מאז
> עלולה לא לעשות כלום בשקט, או לפגוע בקוד בהקשר לא מתוכוון.

| קובץ | מה עשה |
|------|--------|
| `rewrite_gui_style.py` | החלפת פלטת הצבעים ל-Enterprise Design System |
| `rewrite_colors.py`, `rewrite_colors_part2.py`, `rewrite_colors_part3.py` | המרת צבעים קשיחים לטוקנים (`TEXT_PRIMARY`, `ACCENT_COLOR` וכו') |
| `rewrite_lists.py` | שכתוב רינדור כרטיסי הרשימות |
| `rewrite_title.py` | עדכון כותרת החלון |
| `fix_keys.py`, `fix_safe_get.py` | תיקון שמות שדות שגויים בכרטיסים והמרת גישה ישירה ל-`.get()` |
| `fix_updater.py` | ⛔ הסקריפט שהכניס את ביטול אימות ה-TLS ל-`updater.py` — **התיקון בוטל**; כיום `updater.py` מאמת אישורים תמיד (ראה `build_ssl_context`) |

**להבא**: לשינויים בקוד עדיף לערוך את הקובץ ישירות ולהריץ את חבילת הבדיקות
(`python -m unittest discover -s tests`) במקום לייצר סקריפט החלפות חד-פעמי נוסף.
