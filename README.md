# 🧠 Universal AI Memory Hub v1.0.1 Enterprise (Windows Suite)
> **סוויטת הזיכרון והשליטה המלאה למודלי AI – אפליקציית שולחן עבודה מסחרית ועצמאית ל-Windows**

---

## 🌟 מה חדש בגרסה 1.0.1 Enterprise?

1. **🎯 שיוך ערכים וחוקים למודלי AI ספציפיים (Per-AI Target Directives):**
   - **שליטה סלקטיבית:** קביעה עבור כל עובדה, פקודה, איסור, סגנון או קובץ האם הוא מיועד **לכל מודלי ה-AI** המותקנים במחשב (ברירת מחדל), או **רק למודלים ספציפיים** (כגון: Google Antigravity בלבד, Claude Desktop בלבד, Cursor בלבד, Windsurf בלבד, GitHub Copilot בלבד, או Cline/Roo Code).
   - **הזרקה חכמה לפי מודל:** בעת סנכרון לפרויקט, `GEMINI.md` מקבל רק חוקים גלובליים וחוקי Antigravity; `CLAUDE.md` מקבל רק חוקי Claude; `.cursorrules` מקבל רק חוקי Cursor; וכן הלאה.
   - **תצוגה מקדימה לפי מודל:** בורר מודל חדש במסך Live Preview המאפשר לצפות בזמן אמת בבלוק ההנחיות המדויק שכל מודל AI מקבל.
   - **תיוג חזותי ועריכה נוחה:** תג AI מעוצב בכל כרטיסייה וחלון בחירה מותאמת אישית מרובת מודלים.

2. **💬 כריית וחילוץ זיכרונות אוטומטית משיחות AI (Chat Memory Miner):**
   - **סריקה אוטומטית:** איתור וזיהוי אוטומטי של כל שיחות ה-AI במחשב (Antigravity Brain, קובצי שיחה חיצוניים כגון JSONL, JSON, TXT, MD, והדבקה חופשית).
   - **חילוץ חכם מבוסס Gemini:** ניתוח עמוק של השיחה וזיהוי מדויק של עובדות, פקודות קבועות (כמו חתימה), איסורים מחייבים (תיקונים של המשתמש), העדפות סגנון ושפה, והוראות מותנות.
   - **אישור והוספה בקליק:** ממשק הצעות אינטראקטיבי המציג את הכלל המוצע, ציטוט מתוך השיחה, נימוק, ציון ביטחון, בורר תחולה, בורר יעד מודלי AI, וכפתור **"➕ אשר והוסף לזיכרון"**.

2. **☁️ סנכרון ענן מאובטח ללא שרת (GitHub Gist Cloud Sync):**
   - גיבוי וסנכרון מלא של כל הזיכרונות, הפרופילים וההגדרות בין מחשבים שונים בלחיצת כפתור (Push / Pull) באמצעות Gist פרטי ומאובטח.
   - אפשרות לסנכרון ענן אוטומטי בעת כל שמירה.

3. **🤖 בדיקת תקינות חוקים וזיהוי סתירות בעזרת Gemini AI (Sanity Check):**
   - ניתוח חכם של כל החוקים, האיסורים וכללי ההתנהגות המוגדרים.
   - זיהוי סתירות מובנות, כפילויות ועמימות המבלבלת מודלי שפה.
   - הפקת ציון בריאות (Health Score) ודוח המלצות קונקרטיות לחידוד הפרומפטים.

4. **⬆️⬇️ סידור ושינוי עדיפויות חוקים (Priority Reordering):**
   - חיצי `▲` ו-`▼` מהירים לצד כל פריט בכל 5 הקטגוריות וקבצי ההקשר.
   - שליטה מדויקת בסדר ההזרקה של החוקים עבור ה-AI.

5. **📚 קבצי הקשר ומסמכי פרויקט (Project Context Files / Local RAG):**
   - צירוף קובצי אפיון, תיעוד, הגדרות וקוד (`.md`, `.txt`, `.json`, `.py`, וכו').
   - כפתור **"✨ תמצת עם Gemini"** המחלץ תקציר הנחיות ממוקד מתוך הקובץ.
   - אפשרות לפתיחת הקבצים ישירות מסייר המערכת.

5. **🎨 ערכות נושא והתאמה אישית (Themes & Appearance):**
   - החלפה בין **Dark Mode (כהה)**, **Light Mode (בהיר)** ו-**System**.
   - בחירת צבע הדגשה מועדף (Blue, Green, Dark-Blue).

6. **⚡ מקש קיצור גלובלי וחלון Spotlight (`Ctrl+Alt+M`):**
   - פתיחת חלון קלט צף מכל מקום ב-Windows להוספת עובדות וחוקים בזמן אמת.

7. **🕒 מגש המערכת (System Tray):**
   - פעולה שקטה ברקע ליד השעון ב-Windows עם תפריט קליק ימני מהיר.

8. **🎯 חוקים ייעודיים לפי פרויקט (Per-Project Scoping):**
   - הגדרת תחולה גלובלית לכל הפרויקטים או ספציפית לפרויקט נבחר.

9. **🎛️ פרופילים וסביבות עבודה (Workspaces):**
   - מעבר מהיר בין פרופיל "ראשי (כללי)", "פיתוח קוד", "עסקי" או יצירת פרופילים חדשים.

## 🛠️ פיתוח מקומי (Development)

```bash
pip install -r requirements.txt
python gui.py
```

**הרצת הבדיקות** (משתמשות ב-`unittest` מהספרייה הסטנדרטית — אין צורך בהתקנות נוספות):

```bash
python -m unittest discover -s tests
```

הבדיקות כוללות בדיקת עשן ל-GUI שבונה את כל העמודים בפועל (מדלגת אוטומטית בסביבה ללא מסך),
ורצות אוטומטית ב-GitHub Actions בכל push ו-PR (ראה `.github/workflows/ci.yml`).

> **חשוב:** הבדיקות מפנות את מסד הנתונים לתיקייה זמנית דרך משתנה הסביבה `AIMEMORYHUB_DATA_DIR`,
> כך שהן לעולם לא נוגעות ב-`data/memory.json` האמיתי שלך.

**תיקיות שנוצרות אוטומטית ואינן בגיט**: `build/`, `dist/`, `dist_installer/` (נוצרות מחדש על ידי
`build_exe.bat` ו-`compile_inno_setup.bat`), וכן `data/memory.json` וקובצי הגיבוי שלו.

### 🔒 עבודה מאחורי סינון / פרוקסי ארגוני

האפליקציה **תמיד** מאמתת אישורי TLS ומאמתת את שלמות קובץ ההתקנה (SHA-256) לפני הרצתו.
אם אתה מחובר דרך פרוקסי שמבצע SSL Inspection (כגון NetFree), אל תבטל את האימות — הגדר במקום זאת:

```bash
setx AIMEMORYHUB_CA_BUNDLE "C:\path\to\proxy-root-ca.pem"
```
